# Grinder burrs: wear and brushing

Both burr questions are measured in kilograms of coffee, so they hinge on the usage rate: about 2 kg a month by the user's own figure. [[_user/notes/beans-2kg-per-month]]

- Wear: the undated "about 40 kg" in `knowledge/grinder.md` "Burr life" is current by the user's ruling, about 460 kg of rated life left. The rate times ~20 months since install agrees. [[notes/burr-40kg-figure-current]] (corrected)
- Brushing: every 2 kg, about monthly, but the last brush is unrecorded, so the due date is open until the user supplies it. [[notes/burr-brush-due-unknown]] (bet)
